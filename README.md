A web-based chess game featuring a custom-built chess engine.

## About

This project is a chess application built with Next.js and TypeScript.
The main goal of the project is to implement a chess engine from scratch,
including move generation, position evaluation and an AI opponent.

## Tech Stack

- Next.js
- TypeScript
- React
- Tailwind CSS

## Features

- [ ] Chess board
- [ ] Legal move validation
- [ ] Check and checkmate detection
- [ ] Castling
- [ ] En passant
- [ ] Pawn promotion
- [ ] Chess AI
- [ ] Minimax
- [ ] Alpha-beta pruning
- [ ] Multiple difficulty levels
